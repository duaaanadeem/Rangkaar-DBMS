# 🎨 Rangkaar – Art Platform Database Management System

## 📖 Project Overview

Rangkaar is a Database Management System (DBMS) project developed using **Microsoft SQL Server 2022**. It represents an online art marketplace that connects artists, students, and customers through a centralized database. The system manages artworks, orders, payments, internships, exhibitions, and customer interactions while demonstrating advanced SQL concepts.

This project was developed as part of the **Database Management Systems (DBMS)** course.

## 🚀 How to Run

1. Open **SQL Server Management Studio (SSMS)**.
2. Create a new database (or use the provided script).
3. Execute the `RangkaarDatabase.sql` script.
4. Verify that all tables, functions, procedures, views, and triggers are created successfully.
5. Run the sample queries and stored procedures.
